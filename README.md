## About the project
An on-demand package delivery platform that assigns local parcel pickups to the nearest delivery rider, optimizes multi-stop routing, and enforces OTP verification at the destination.

**Actors:** Sender Client, Delivery Rider (supporting: Routing / GPS Service)

**Requirements:** 5 Functional Requirements (FR-001 to FR-005) and 2 Non-Functional Requirements (NFR-001, NFR-002).
